ՏԱՐՈՆ ԵՎ ԶՈՅԱ — ՎԵՐՋՆԱԿԱՆ ՏԱՐԲԵՐԱԿ

Netlify-ում թարմացնելու համար.
1. Բացեք այս ZIP ֆայլը և Extract արեք։
2. Netlify-ում բացեք tzwedding կայքը։
3. Գնացեք Deploys բաժին։
4. Քաշեք ամբողջ tzwedding թղթապանակը deploy հատվածի վրա։
5. Սպասեք, մինչև Deploy published գրությունը երևա։

Հղման նախադիտման նկարը որոշ հավելվածներում կարող է պահպանվել հին cache-ով։
Այդ դեպքում հղումը մեկ անգամ ուղարկեք նոր հաղորդագրությամբ կամ փոքր ժամանակ անց կրկին փորձեք։
